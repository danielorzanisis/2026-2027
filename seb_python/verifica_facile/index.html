Verifica di Python — Prova A

Per scrivere ed eseguire il codice, apri Apri Python.

INDICAZIONI

Per ogni esercizio definisci la funzione richiesta e utilizzala almeno una volta per controllare che soddisfi i requisiti.
I dati arrivano alla funzione attraverso i parametri (input alla funzione): non occorre usare la funzione input().
Tutte le operazioni richieste devono stare dentro la funzione.
Per gli esercizi che richiedono di scorrere una lista o una stringa, usa un ciclo while.

Es. 1 — Abbreviazione di un testo (4 punti)

Scrivi una funzione abbrevia(testo) che riceve una stringa.

Se la stringa contiene più di 5 caratteri, la funzione deve restituire i primi 5 caratteri seguiti da "...". Altrimenti deve restituire la stringa originale.

abbrevia("informatica") → "infor..."
abbrevia("scuola")      → "scuol..."
abbrevia("ciao")        → "ciao"
abbrevia("")            → ""

Es. 2 — Modificare l’ordine dei turni (6 punti)

Scrivi una funzione aggiorna_turni(persone, nuovo) che riceve una lista di nomi e il nome di una nuova persona. La lista contiene almeno 3 elementi.

La funzione deve:

  • creare una nuova lista contenente tutte le persone tranne la prima, mantenendo l’ordine;
  • aggiungere alla fine della nuova lista la persona che era prima nella lista originale;
  • inserire nuovo in seconda posizione, all’indice 1;
  • restituire la nuova lista.

La lista originale deve rimanere invariata.

aggiorna_turni(["Anna", "Luca", "Sara", "Paolo"], "Marta")
→ ["Luca", "Marta", "Sara", "Paolo", "Anna"]

Es. 3 — Correggere le misurazioni (8 punti)

Scrivi una funzione correggi_misure(misure) che riceve una lista di numeri interi.

La funzione deve restituire una nuova lista della stessa lunghezza, nella quale ogni numero negativo è sostituito da 0. Gli altri numeri devono mantenere il proprio valore e la propria posizione.

La funzione deve funzionare anche con una lista vuota. La lista originale deve rimanere invariata.

correggi_misure([12, -3, 0, 7, -1]) → [12, 0, 0, 7, 0]
correggi_misure([-4, -2, -8])       → [0, 0, 0]
correggi_misure([])                → []
