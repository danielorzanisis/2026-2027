Verifica di Python — Prova A guidata

Per scrivere ed eseguire il codice, apri Apri Python.

INDICAZIONI

Per ogni esercizio definisci la funzione richiesta e utilizzala almeno una volta per controllare che soddisfi i requisiti.
I dati arrivano alla funzione attraverso i parametri (input alla funzione): non occorre usare la funzione input().
Tutte le operazioni richieste devono stare dentro la funzione.

Es. 1 — Abbreviazione di un testo (4 punti)

Scrivi una funzione abbrevia(testo) che riceve:

  • testo: una stringa, anche vuota.

La funzione deve:

  1. Calcolare la lunghezza della stringa usando len().
  2. Se la lunghezza è maggiore di 5, prendere i primi 5 caratteri usando lo slicing. Aggiungere alla fine "..." usando la concatenazione con +.
  3. Altrimenti mantenere la stringa originale.
  4. Restituire la stringa ottenuta usando return.

Esempi

abbrevia("informatica") → "infor..."
abbrevia("ciao")        → "ciao"
abbrevia("verde")       → "verde"
abbrevia("")            → ""

Es. 2 — Modificare l’ordine dei turni (6 punti)

Scrivi una funzione aggiorna_turni(persone, nuovo) che riceve:

  • persone: una lista con almeno 3 nomi;
  • nuovo: una stringa con il nome della nuova persona.

La funzione deve:

  1. Creare una nuova lista con tutte le persone tranne la prima, usando lo slicing a partire dall’indice 1.
  2. Prendere la prima persona dalla lista originale persone. Si trova all’indice 0.
  3. Aggiungere questa persona alla fine della nuova lista, usando append().
  4. Inserire nuovo in seconda posizione nella nuova lista, usando insert() con indice 1.
  5. Restituire la nuova lista usando return.

La lista originale persone deve rimanere invariata.

Esempio

aggiorna_turni(["Anna", "Luca", "Sara", "Paolo"], "Marta")
→ ["Luca", "Marta", "Sara", "Paolo", "Anna"]

Es. 3 — Correggere le misurazioni (8 punti)

Scrivi una funzione correggi_misure(misure) che riceve:

  • misure: una lista di numeri interi, anche vuota.

La funzione deve:

  1. Creare una nuova lista vuota.
  2. Creare un indice i con valore iniziale 0.
  3. Scorrere la lista con un ciclo while, finché i è minore della lunghezza di misure.
  4. A ogni giro controllare il numero misure[i]:
    • se è minore di 0, aggiungere 0 alla nuova lista con append();
    • altrimenti aggiungere il numero originale misure[i].
  5. Aumentare i di 1 alla fine di ogni giro, in entrambi i casi.
  6. Dopo il ciclo, restituire la nuova lista usando return.

La nuova lista deve avere la stessa lunghezza di quella originale. La lista originale deve rimanere invariata.

Esempi

correggi_misure([12, -3, 0, 7, -1]) → [12, 0, 0, 7, 0]
correggi_misure([-4, -2, -8])       → [0, 0, 0]
correggi_misure([])                → []
